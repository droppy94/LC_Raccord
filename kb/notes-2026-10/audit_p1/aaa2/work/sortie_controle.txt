== Tache 4 : Int_0^inf dk sin(2 k eta) e^{-a k} ==
forme fermee sympy  Int sin(2k eta) e^{-ak} dk = 2*eta/(a**2 + 4*eta**2)
forme fermee sympy  Int cos(2k eta) e^{-ak} dk = a/(a**2 + 4*eta**2)
eta * Int sin : limite a -> 0+ (eta != 0) = 1/2
Int e^{-2ik eta} e^{-ak} dk = Int cos - i Int sin = 1/(a + 2*I*eta)  = 1/(a + 2 i eta)
  => limite a->0 : 1/(2 i eta) = -i/(2 eta) ; partie imaginaire -1/(2 eta) = -Int sin ; eta * Int sin = +1/2
  eta = -0.1  eta*Int (quad par morceaux) = 0.499987501068  forme fermee = 0.499987500312
  eta = -0.05  eta*Int (quad par morceaux) = 0.499950005369  forme fermee = 0.499950005
  eta = -0.02  eta*Int (quad par morceaux) = 0.499687695629  forme fermee = 0.499687695191
  eta = 0.05  eta*Int (quad par morceaux) = 0.499950005369  forme fermee = 0.499950005
Conclusion : la quantite imprimee par le script tend vers +1/2 (quel que soit le signe de eta) ; l'annotation « attendu -1/2 » est fausse (signe).

== Tache 5 : borne generale ==
  T^tf_ij(eta) = (2 pi)^{-3} Int dk k^3 Re[ e^{-2ik eta} M_ij(k) ],  M_ij(k) = Int dOmega F(k,Omega) (n_i n_j - delta_ij/3)
  |M_ij(k)| <= (2/3) Int dOmega |F(k,Omega)|  =>  |T^tf_ij(eta)| <= (2/3)(2pi)^{-3} Int d^3k k |F(k)|  pour tout eta  [derive]
  Si F decroit rapidement (uniformement en direction), le membre de droite est fini : T^tf borne, continu (Riemann-Lebesgue),
  meme C^infini si tous les moments existent. Un comportement en 1/eta est donc impossible. La dependance angulaire n'y change rien.
  Le 1/eta du cas N=3 provient de la queue k -> infini (k ~ 1/|eta|), pas de l'infrarouge.
