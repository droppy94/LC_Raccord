Formule generale : int_mu^inf k^{3-N} e^{-a k} dk = a^{N-4} Gamma(4-N, a mu),  a = 2 i eta = -2 i s
Pour mu -> 0 et N < 4 : a^{N-4} Gamma(4-N) ; definie par continuation analytique (Abel : a -> a + epsilon).

N = 3 : I_3 =  I/(2*s)   = i/(2 s) : |I_3| ~ s^{-1}
N = 3 avec coupure mu : I_3 = e^{-a mu}/a = I/(2*s) - mu - I*mu**2*s + O(s**2)

N = 4 : I_4 = E_1(a mu), developpement : I*pi/2 - EulerGamma - log(2) - log(s) - log(mu) - 2*I*mu*s + O(s**2)
   -> terme dominant : -ln(s) (log(a mu) = ln(2 s mu) - i pi/2)

N = 5 : I_5 = a Gamma(-1, a mu), developpement : (mu*(-s*(I*log(4*mu**2*s**2) + pi - 2*I + 2*EulerGamma*I) + O(s**2)) + 1)/mu
   -> constante IR 1/mu, puis terme en s ln s et terme lineaire en s ; pas de terme singulier.

Gaussien : I_G = -Lambda**2*(-I*(2*Lambda**2*s**2 - 3)*(2*sqrt(pi)*Lambda**3*s**3*(erfc(I*Lambda*s) - 2) + I*(2*Lambda**2*s**2 + 1)*exp(Lambda**2*s**2)) + 3*exp(Lambda**2*s**2))*exp(-Lambda**2*s**2)/(8*s**2)
  developpement en s : Lambda**4/2 + 3*I*sqrt(pi)*Lambda**5*s/4 - 2*Lambda**6*s**2 + O(s**3)
  valeur en s=0 (limite) : Lambda**4/2   (= Lambda^4/2)
  => fonction entiere de s : regulier, pas de singularite en s -> 0.

Loi generale (mu -> 0, N < 4 non entier, ou partie singuliere pour N >= 4) : I_N ~ Gamma(4-N) (-2 i s)^{N-4}
  N=3 : s^{-1} ; N=4 : ln s ; N=5 : s ln s (apres soustraction de la constante IR 1/mu).
