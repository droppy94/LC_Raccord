## Cadre
Conventions de H. Friedrich (arXiv:1311.0700) : signature (-,+,+,+) ; metrique physique ghat = Omega^-2 g ; Einstein Rhat_ab - (1/2) Rhat ghat_ab + lambda ghat_ab = kappa That_ab. Inconnues : Omega, n_a = d_a Omega, s = (1/4) box Omega + (1/24) Omega R, le Schouten L de g, W = Omega^-1 C (C : Weyl de g), et les champs de matiere. Equations utilisees (verifiees) : (2.14) nabla_a nabla_b Omega = s g_ab - Omega L_ab + (kappa/2) Omega T*_ab ; (2.15) nabla_c s = -n^b L_bc + (kappa/2) n^b T*_bc - (kappa/24) Omega^-1 nablahat_c That ; (3.8) |dOmega|^2 = -lambda/3 + 2 Omega s + (kappa/12) That ; (2.17) nabla_mu W^mu_rho nu lambda = R_rho nu lambda := Omega^-1 (nablahat_nu Lhat_lambda rho - nablahat_lambda Lhat_nu rho), Lhat_ab = (kappa/2)(That_ab - (1/3) That ghat_ab) + (lambda/6) ghat_ab. « Formellement regulier » : les seconds membres, comme fonctions des inconnues (et de leurs derivees, traitees comme inconnues independantes), ne contiennent ni Omega^-k (k > 0) ni ln Omega.

Travaillez au **premier ordre** autour de g = eta (de Sitter est conformement plat) : a cet ordre, d_a d_b Omega = s eta_ab, d_c s = 0, |dOmega|^2 = -lambda/3 + 2 Omega s ; tout produit de deux quantites du premier ordre est neglige.

## Questions
- **Q1 (partie c de l'anomalie).** Le terme de Wess-Zumino b Int sqrt(g) sigma C^2, sigma = -ln Omega, donne au premier ordre T_ab = c0 b d^c d^d (sigma C_acbd) (lineaire en C ; c0 constante de normalisation, |c0| = 8, le signe dependant de la convention de T ; gardez c0 symbolique) et That_ab = Omega^2 T_ab. Substituez C = Omega W, W tenseur de Weyl generique et ses derivees comme inconnues. Ecrivez T comme somme de termes en Omega^-1, Omega^0 et ln Omega. Montrez que la partie en ln Omega est sigma fois une combinaison lineaire de la divergence D_abc = d^d W_abcd et de ses derivees. Donnez le coefficient de Omega^1 dans That.
- **Q2.** Calculez la plus basse puissance de Omega dans le second membre R de (2.17) et son coefficient, comme fonction des inconnues ; exprimez-le avec E^n_ab = n^c n^d W_acbd. Depend-il des derivees de W ?
- **Q3.** Montrez (par resolution explicite des contraintes D = 0, dD = 0, ddD = 0 sur les jets de W) que tous les termes en ln Omega de R s'annulent quand W est a divergence nulle. Que reste-t-il si D = J != 0 (matiere classique) ?
- **Q4 (sigma F^2).** Avec le terme beta_* Int sqrt(g) sigma F_ab F^ab ajoute au Maxwell -(1/(4 e^2)) Int sqrt(g) F^2 (couplage effectif 1/e^2 - 4 beta_* sigma, F de poids conforme 0), ecrivez l'equation de Maxwell rescalee au premier ordre en beta_* : son second membre est-il formellement singulier, et avec quel coefficient ? Avec That = (1/e^2 + 4 beta_* ln Omega) Omega^2 M_ab (M tenseur de Maxwell de F dans eta, sans trace), donnez les termes en ln Omega de R et la condition algebrique (en E_i = F_0i, B_i dans le repere ou n = (1,0,0,0)) de leur annulation ; pour des champs reels, que reste-t-il ?
- **Q5 (controles).** (a) Sur n = (1,0,0,0), lambda = 3, s = 0, W purement electrique avec E_yy = -E_zz = e, donnez le pole de R_{y 0 y} pour c0 = -8. (b) Sur F_12 = B0 (champ magnetique uniforme), n = (1,0,0,0), lambda = 3, s = 0, beta_* = -beta~/(2 e^2), donnez les coefficients de ln Omega de R_{1 0 1}, R_{2 0 2}, R_{3 0 3}.
