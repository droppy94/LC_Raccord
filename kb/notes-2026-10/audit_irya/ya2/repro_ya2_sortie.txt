######## D. Tenseur energie-impulsion du scalaire sans masse, couplage xi, etat homogene isotrope de Bogoliubov sur Minkowski

  Mode : v_k = alpha u_k + beta u_k*, u_k = e^{-ik eta}/sqrt(2k) (x e^{ik.x}). Termes croises alpha beta* dans <T_{mu nu}> : angulairement moyennes.
  terme croise de <T_00> (par mode, apres moyenne angulaire) : 0
  terme croise de <T_ij>/delta_ij (par mode, apres moyenne angulaire) : kk*(AB + BA*exp(4*I*eta*kk))*(6*xi - 1)*exp(-2*I*eta*kk)/3

######## E. Contre-exemples cherches : T^w ~ 1/eta sans singularite de w dans le domaine eta, eta' < 0 ?
  Cadre : terme alpha beta* en coincidence : C(eta) = Re int_0^inf dk g(k) e^{-2 i k eta}, g = k^3 alpha beta* (pour xi != 1/6). Abel-regularise.
  (i) phase lineaire alpha beta* = k^{-3} e^{2 i k eta_0} (etat translate en temps) : int dk e^{2ik(eta_0-eta)} = -I/(2*eta - 2*eta_0)  : pole en eta = eta_0, pas en 0. Pour eta_0 < 0 la singularite de T^w est DANS le domaine ; pour eta_0 > 0 T^w est lisse en 0- mais w est singulier sur le cone r = |eta+eta' - 2 eta_0| qui coupe le domaine. [calcule]
  (ii) oscillant alpha beta* = k^{-3} cos(k ell) : int dk cos(k ell) e^{-2ik eta} = 2*I*eta/(ell**2 - 4*eta**2)  : poles en eta = +-ell/2, rien en eta = 0 : pas de 1/eta ; w singulier sur les cones r = |T +- ell| (dans le domaine). [calcule]
  (iii) support compact alpha beta* = k^{-3} 1_{k<K} : int_0^K dk e^{-2ik eta} = Piecewise((-I/(2*eta) + I*exp(-2*I*K*eta)/(2*eta), (eta > 0) | (eta < 0)), (K, True))  : fonction ENTIERE de eta (singularite apparente en 0 levable) ; w entiere en (T, x) : ni 1/eta, ni cone. [calcule]
  (iv) argument general [derive] : w_ab(T, x) := int d^3k/(2k(2pi)^3) 2Re(alpha beta* e^{-ikT}) e^{ik.x} est une solution distributionnelle de l'equation des ondes en (T, x) sur R^4 (chaque mode e^{-ikT+ik.x} avec |k| = k l'est).
      Si T^w ~ 1/eta en eta -> 0-, alors w_ab n'est pas C^inf au point (T=0, x=0) (sinon la limite de coincidence et ses derivees seraient lisses en eta = 0).
      Par propagation des singularites (Hormander : WF(u) invariant par le flot bicaracteristique nul pour Box u = 0), la singularite en (0,0) se propage le long d'un rayon nul T = -|x| vers T < 0,
      c'est-a-dire sur des points (eta+eta' = T < 0, |x-x'| = |T|) : par exemple eta = eta' = T/2 < 0. Donc w est singulier dans le domaine eta, eta' < 0.
      Conclusion : AUCUNE famille alpha beta* (temperee, homogene) ne donne T^w ~ 1/eta sans singularite de w dans le domaine. Les familles oscillantes deplacent la singularite, les supports compacts la suppriment avec le 1/eta. [derive]
      (Pour le scalaire conforme la question est vide : le terme alpha beta* de T^w est identiquement nul, cf. D.)
